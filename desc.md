# Прототип экрана «Заявки на выезд»

Кликабельный прототип одного экрана Центра управления для тестового задания.

- `prototype.html` — весь прототип: разметка, стили и логика в одном файле,
  открывается двойным кликом, работает без интернета и без установки чего-либо.
- `index.html` — редирект на прототип, чтобы корневой адрес GitHub Pages открывал экран сразу.

Пять сценариев переключаются кнопками сверху: обычная работа, конфликт назначения,
данные недоступны, недостаточно прав, возможный дубль. Данные внутри файла, бэкенда нет.
